# unversioned Yahoo Finance API that changes without notice, and 0.x -> 1.x
# was a compatibility-breaking rewrite in response to exactly that. Pinning

# version that could no longer authenticate with Yahoo at all, failing

# fresh build (Vercel's build has no lockfile, so this does resolve fresh
# every deploy) trades reproducibility for actually working.
