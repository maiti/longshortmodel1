Long/Short Equity Factor Model

A validated, honestly-uncertain quant strategy — not investment advice
Running backtest…

What this is: a computer program that looks at a group of stocks every month, ranks them by a few measurable traits, buys ("goes long") the ones that rank best, and bets against ("goes short") the ones that rank worst — while trying to keep overall risk steady and account for the real cost of trading.

How to read the numbers below: "Sharpe ratio" is a return-per-unit-of-risk score — roughly, higher is better, and anything reliably above 0 for a long/short stock strategy is considered respectable. The important trick this project takes seriously: a strategy can look great on the data it was tuned on and still be worthless — so every result below is also checked on "out of sample" data the tuning never got to see.

1. Factor scoring
Each stock gets a z-score for every factor, cross-sectionally (relative to the rest of the universe on that same date):
z_i,t = (x_i,t - mean(x_.,t)) / std(x_.,t)
Then a weighted composite, optionally demeaned within each GICS sector:
composite_i,t = w_mom*z_mom + w_rev*z_rev + w_vol*z_lowvol + w_illiq*z_illiq
Information Coefficient — does each factor actually predict returns?

The Information Coefficient (IC) is the correlation between a factor's score on a given date and that stock's actual future return to the next rebalance. It is computed only on in-sample dates, before the factor weights above are chosen — otherwise the weight choice would have already seen the data it's later tested against. Rule of thumb: a mean IC above ~0.02–0.05 with a consistent sign is a real, usable signal; anything near zero is noise.

2. Position sizing — the tangency portfolio
Generalizes the single-asset Merton fraction to the full covariance matrix across selected names:
w = (1 / gamma) * Sigma-1 * (mu - r)
Sigma is shrunk toward its own diagonal for stability: Sigma_shrunk = (1-s)*Sigma_sample + s*diag(Sigma_sample)
3. Volatility targeting & trading costs
Leverage each rebalance solves for a target book volatility using only already-realized returns:
leverage_t = clip(vol_target / realized_vol_t, min_leverage, max_leverage)
Market impact cost uses a square-root law (Almgren-Chriss family):
cost_fraction = impact_coef * sqrt(trade_dollars / avg_daily_dollar_volume)
